# Daily Task Planner

A browser-based Daily Task Planner built using HTML5, CSS3, Bootstrap 5 and JavaScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed/pending
- Current date display
- Enter key support
- localStorage persistence
- High / Medium / Low priority
- Categories
- Due date and time
- Overdue task detection
- Search tasks
- Filter All / Pending / Completed / Overdue
- Sort by priority, date, status and title
- Task statistics
- Progress bar
- Clear completed tasks
- Light / Dark mode
- Responsive mobile design

## How to Run in VS Code

1. Open VS Code.
2. Select File > Open Folder.
3. Open the `daily-task-planner` folder.
4. Open `index.html`.
5. Install the VS Code extension "Live Server" if you do not already have it.
6. Right-click `index.html`.
7. Select "Open with Live Server".

The project can also work by opening `index.html` directly in a browser.

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Browser localStorage

## Data Storage

Tasks are saved in the browser using localStorage. No backend or database is required.
